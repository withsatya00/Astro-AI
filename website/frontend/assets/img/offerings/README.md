# Offering thumbnails

Six AI-generated illustrative catalog photographs created for this website: flowers/bilva/diya, panchamrit and bhasma, diya tray, bhog, havan materials and a general puja thali.

These are representations of offering categories, not photographs of a customer's ceremony or proof of fulfilment. The UI labels them as illustrative. A supplied offering-specific image takes priority over the category image. The source originals are preserved in the generation library; these 480px WebP assets are optimized website copies.
